# Shortsmith

**Long videos in. Viral shorts out.** Shortsmith is a Windows app that turns long YouTube, Twitch and podcast videos into vertical shorts. It finds the moments people replay, reframes them to 9:16 around whoever is talking, and burns in word-perfect animated captions, all on your own PC.

**Website:** https://shortsmith.lol
**Download:** [Shortsmith-win64.zip](https://github.com/AniEEEEeee/shortsmith/releases/latest/download/Shortsmith-win64.zip) (latest release)

## Install

1. Download `Shortsmith-win64.zip` from the [latest release](https://github.com/AniEEEEeee/shortsmith/releases/latest).
2. Unzip it somewhere with a short path, for example `C:\Apps\Shortsmith` or your Desktop.
3. Run `Shortsmith\Shortsmith.exe`. Keep the whole folder together.

The app isn't code-signed yet, so Windows SmartScreen may warn you the first time. Click **More info → Run anyway**.

## Features

- Paste a link or drop a file: YouTube, TikTok, Twitch, X, Vimeo, Instagram or a local video.
- Whisper speech recognition with word-level timing, in 90+ languages.
- Moment detection that scores every candidate clip on hook, energy, pacing and audience replays. Optional Claude AI picks with your own Anthropic API key.
- Smart 9:16 reframing: face tracking, two-speaker split screen, and blurred-background fit for slides.
- 12 animated caption styles with 14 fonts, fully customizable, with editable words and .srt export.
- Discover: hundreds of recommended videos to clip, refreshed every time you open the app.
- NVIDIA GPU acceleration (optional, one click), NVENC encoding, −14 LUFS loudness.

## Requirements

Windows 10 or 11 (64-bit), 8 GB RAM (16 GB recommended). An NVIDIA GPU is optional.
